ClassQuill provides scheduling, invoicing, payroll, and a learning platform for tutoring businesses. It offers an operating system that automates lesson creation, auto‑marks practice, and gives tutors and parents visibility into results. Pricing starts at US$20 per month for the first tutor, with additional tutors at US$6 each.

**Areas:** Tutoring · Scheduling · Invoicing · Payroll · LearningPlatform · Education

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for ClassQuill: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
